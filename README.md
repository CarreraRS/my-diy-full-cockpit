# DIY Sim Racing Full Cockpit (โครงเหล็ก ถอดแยกได้)

แบบ Full cockpit สำหรับ Sim racing ทำจาก **เหล็กกล่อง 50x50x2.3 และ 38x38x2.3** ขนาดมาตรฐาน ยึดด้วยน็อต M10 ทั้งหมด **ถอดแยกได้ 6 ชุด**

| ส่วน | ปรับได้ |
|---|---|
| เบาะ | หน้า-หลัง (รูบนราง 5 ระดับ + รางสไลด์ ~180 มม.), ความสูง 3 ระดับ, มุมเงย |
| แป้นเหยียบ | หน้า-หลัง 10 ระดับ (ทุก 25 มม.), องศาแผ่นแป้น 15–45° |
| แท่นพวงมาลัย | ความสูง 11 ระดับ (ทุก 25 มม.), มุมก้ม 0–20° |
| ขาติดเกียร์ | หน้า-หลัง 5 ระดับ, ความสูงปรับได้ไม่มีขั้น, ย้ายซ้าย/ขวาได้ |

ขนาดรวม ยาว 1,500 × กว้าง 560 (660 รวมเสา) มม. · งบโครงเหล็กประมาณ 5,000–8,000 บาท

## เนื้อหา
- **เว็บดูแบบ** (`index.html`): โมเดล 3D หมุน/ซูม/แยกชิ้นได้ + สไลเดอร์ทดลองปรับตำแหน่ง, แบบแปลน 2D พร้อมขนาด (พิมพ์เป็น PDF ได้), เอกสารวัสดุและวิธีทำ
- **แปลนและวิธีทำแบบละเอียด**: [`docs/PLAN.md`](docs/PLAN.md) — รายการวัสดุ, cut list, ตำแหน่งรูเจาะ, ขั้นตอนเชื่อม/ประกอบ, การปรับตั้งตามส่วนสูง
- ขนาดทั้งหมดอยู่ใน [`assets/js/params.js`](assets/js/params.js) ไฟล์เดียว — โมเดล 3D และแบบแปลนอ่านจากไฟล์นี้

## เปิดเว็บ
**บน GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → เลือก branch และโฟลเดอร์ `/ (root)` → Save แล้วเปิด `https://<username>.github.io/my-diy-full-cockpit/`

**บนเครื่อง:** ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เพราะเว็บโหลดไฟล์ `docs/PLAN.md` และ ES modules)
```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

ใช้ [Three.js](https://threejs.org/) และ [marked](https://marked.js.org/) ผ่าน CDN ไม่ต้องติดตั้งอะไรเพิ่ม
